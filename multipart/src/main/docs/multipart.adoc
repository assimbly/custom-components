= MULTIPART Component
:doctitle: MULTIPART

:description: Converts binary to multipart
:since: 2.23.0
:supportlevel: Stable
:component-header: Producer is supported
//Manually maintained attributes

*Since Camel {since}*

*{component-header}*

The Multipart component translates a binary body to a multipart form data body

Maven users will need to add the following dependency to their `pom.xml`
for this component:

[source,xml]
------------------------------------------------------------
<dependency>
    <groupId>org.assimbly</groupId>
    <artifactId>xmltocsv</artifactId>
	<version>x.x.x</version>
    <!-- use the same version as your Assimbly version -->
</dependency>
------------------------------------------------------------

== URI format

--------------------------------------------
none
--------------------------------------------

== Headers

[width="100%",cols="2,5",options="header"]
|===
| Header | Description
| MultipartFieldName | Form field name for the binary body part (required).
| MultipartFormFields | Optional JSON object of additional text form fields. Example: `{"options":{"to_formats":["md"],"force_ocr":true}}`. Nested objects/arrays are serialized as JSON strings. Values may also be plain strings.
|===

== Route example

    <setHeader headerName="MultipartFieldName">
      <simple>files</simple>
    </setHeader>
    <setHeader headerName="MultipartFormFields">
      <constant>{"options":{"to_formats":["md"],"force_ocr":true}}</constant>
    </setHeader>
    <process ref="multipartProcessor"/>
