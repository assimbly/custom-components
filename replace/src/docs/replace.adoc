= Replace Component
:doctitle: REPLACE
:shortname: replace
:artifactid: replace
:description: Replaces text in the message body using a regular expression
:since: 3.0.3
:supportlevel: Stable
:component-header: Only producer is supported
//Manually maintained attributes

*Since Camel {since}*

*{component-header}*

The component replaces text in the message body that matches a regular expression.

Maven users will need to add the following dependency to their `pom.xml`
for this component:

[source,xml]
------------------------------------------------------------
<dependency>
    <groupId>org.assimbly</groupId>
    <artifactId>replace</artifactId>
	<version>x.x.x</version>
    <!-- use the same version as your Assimbly version -->
</dependency>
------------------------------------------------------------

== URI format

--------------------------------------------
replace://?regex=[regex]&replaceWith=[text]
--------------------------------------------

== Options

[width="100%",cols="2,5,^1,2",options="header"]
|===
| Name | Description | Default | Type
| *regex* | *Required* Regex pattern that matches the text to replace. | | String
| *replaceWith* | *Required* Text to replace the match(es) with. | | String
| *group* | Group of the regex match to replace. | 0 | int
| *flags* | Comma separated regex flags: `i` (case insensitive), `m` (multiline), `s` (dotall). | | String
|===
